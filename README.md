
# SkillSync

A student skill development and profile management platform.

## About
SkillSync is a web-based project designed to help students create profiles and present their skills in one place.

## Features
- Student profile management
- Skill discovery
- Simple and user-friendly interface
- Web-based platform

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js

## How to Run
1. Install Node.js.
2. Open the project folder in VS Code.
3. Install dependencies using `npm install`.
4. Start the server using `node server.js`.
5. Open `http://localhost:3000` in your browser.
